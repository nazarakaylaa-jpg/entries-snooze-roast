Entry for the [Snooze Button Roast](https://make.fun/c/u-carbon-forge-snooze-button-roast-14cbafc6) competition on make.fun.

## The entry

> "My alarm rang at 6 AM on a Saturday with the confidence of a man who has never checked a calendar — congratulations, you're the only thing in this house with a job today."

## How it works

`main.ts` writes the one-line roast (170 characters, a single line,
punchline at the end) to `/output/entry.txt`. Run it locally with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
